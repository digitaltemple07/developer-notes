# developer-notes
My personal knowledge base documenting my journey to becoming a Full-Stack Developer.
### About
This repository contains everything I learn while studying software development.

Rather than relying on memory, I document every concept I learn with explanations, examples, commands, screenshots, and practical exercises.

My goal is to build a complete reference that I can revisit at any time while also helping others who are learning the same technologies.
### Learning Philosophy
> Learn → Practice → Document → Build → Teach
I believe writing about what I learn helps me understand concepts more deeply and creates a valuable resource for future projects.
