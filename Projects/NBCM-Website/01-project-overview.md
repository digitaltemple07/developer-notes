# NBCM Website — Project Background

## 1. Introduction

The **Neo Black Consciousness Movement (NBCM) Website** is a web development project I created to establish a modern digital platform for the Neo Black Consciousness Movement.

The purpose of the project is not simply to create an attractive website. My goal is to build a serious educational and civic platform where people can learn about African history, political consciousness, ethical leadership, human rights, good governance, responsible citizenship, and the ideas that have shaped struggles for liberation and social progress.

The project also became an opportunity for me to apply and expand my web development skills while learning how modern AI-assisted software development tools can be incorporated into a real development workflow.

---

## 2. Why I Built the NBCM Website

I wanted NBCM to have a digital presence that reflects the seriousness of its mission.

Rather than presenting the movement through a basic informational website, I wanted to create something that feels like a **modern educational and civic institution**.

The website should provide visitors with a place where they can:

* learn about NBCM and its mission;
* study African and Black history;
* explore ideas surrounding liberation and consciousness;
* learn about civic responsibility and ethical leadership;
* access educational materials and knowledge resources;
* understand issues relating to human rights and good governance;
* participate in the movement;
* volunteer;
* become members;
* and support the work of NBCM.

The website therefore serves both an **educational purpose** and an **institutional purpose**.

---

## 3. The Problem I Wanted to Solve

An organization may have important ideas, research, educational materials, and objectives, but without an effective digital platform, that information can be difficult for people to discover and engage with.

I wanted to create a website that could organize NBCM's ideas and resources into a structured and accessible digital experience.

Instead of visitors encountering disconnected information, the website should provide clear pathways through areas such as:

* **About** — understanding NBCM and what it represents;
* **Learning** — educational materials and structured learning;
* **Knowledge** — historical, political, civic, and intellectual resources;
* **Participate** — ways visitors can become involved in the movement.

The goal is to transform the website from a simple collection of pages into a platform where visitors can **read, learn, explore, participate, volunteer, and support the movement**.

---

## 4. Educational and Civic Purpose

A major objective of the project is to present NBCM as a serious educational and civic institution.

The website is intended to support subjects including:

* historical scholarship;
* civic education;
* ethical leadership;
* good governance;
* human rights;
* constitutional democracy;
* responsible citizenship;
* political consciousness;
* and the development of informed citizens.

The website should encourage people not only to consume information but also to think critically about history, leadership, governance, society, and their responsibilities as citizens.

For this reason, the project places a strong emphasis on **education and knowledge** rather than simply promoting an organization.

---

## 5. Design Goals

I wanted the website's visual identity to communicate credibility, seriousness, history, and intellectual depth.

The design brief therefore called for features such as:

* readable typography;
* modern cards;
* professional icons;
* high-quality African-inspired imagery;
* clean whitespace;
* accessibility-friendly design;
* search functionality;
* newsletter integration;
* social sharing functionality;
* and a premium institutional appearance.

The final visual direction uses a dark editorial design with gold accents, strong typography, structured content sections, and carefully designed calls to action.

The intention is for visitors to feel that they are interacting with an established educational and civic institution rather than a generic template website.

---

## 6. Why I Used Lovable

Another important objective of this project was to explore **AI-assisted development**, sometimes referred to as *vibe coding*.

Instead of building the first version of the website entirely by manually writing every component from scratch, I provided my website requirements and design direction to **Lovable** and used its AI development capabilities to generate and refine the application.

This allowed me to explore a different software development workflow:

```text
Idea
  ↓
Website Requirements
  ↓
AI Prompt
  ↓
Lovable
  ↓
Generated Application
  ↓
Review
  ↓
Refinement
  ↓
GitHub
  ↓
Local Development
```

However, my objective was not simply to allow AI to build something that I did not understand.

I wanted to go beyond generating the website and learn how to **take ownership of the generated project**.

That meant understanding how to access the source code, store it in GitHub, download it to my computer, run it locally, modify it myself, and manage future changes using Git.

---

## 7. Taking Ownership of the Source Code

After generating the website with Lovable, my next objective was to move beyond working exclusively inside the AI builder.

I connected the Lovable project to **GitHub**.

This gave me access to the actual project repository and introduced an important transition in the project:

```text
Lovable
   ↓
GitHub
   ↓
My Local Computer
   ↓
VS Code
```

I then cloned the repository onto my Windows computer and opened the project in Visual Studio Code.

This was an important part of the project because the website was no longer something that existed only inside Lovable.

I now had the source code locally and could begin understanding, testing, modifying, and managing the application myself.

---

## 8. Building a Local Development Environment

To work with the project locally, I also needed to establish a development environment on my computer.

During this process, I worked with technologies and tools including:

* Visual Studio Code;
* Git;
* GitHub;
* SSH authentication;
* Node.js;
* npm;
* Vite;
* PowerShell;
* and Lovable.

I learned how the different tools fit together rather than viewing them as isolated technologies.

My development environment gradually became:

```text

                   ▼
                GitHub
                   │

                   │
                   ▼
              Local Computer
                   │

                   │
```

---

## 9. Learning Git and GitHub Through a Real Project

The NBCM website also became a practical environment for learning Git.

Rather than learning Git commands only as abstract examples, I was able to use them on a real project.

I learned the basic development cycle:

```text
Modify a file
      ↓
git status
      ↓
Review changes
      ↓
git add
      ↓
git commit
      ↓
git push
      ↓
GitHub
```

One of my first controlled modifications was updating the project's `README.md`.

I staged the change, created a Git commit, and pushed the commit back to GitHub.

That exercise helped me understand that Git is not simply a tool for uploading files to GitHub. It is a system for tracking the history and evolution of a software project.

---

## 10. Troubleshooting as Part of the Learning Process

The project also introduced several real development problems that I had to investigate and solve.

These included:

* Node.js initially not being available on my computer;
* PowerShell preventing npm scripts from running;
* accidentally running Git commands outside the project repository;
* understanding the difference between local and remote repositories;
* dealing with Windows `CRLF` and Unix/Linux `LF` line endings;
* understanding generated files;
* distinguishing npm-generated files from the project's existing Bun configuration;
* and learning when **not** to commit a file.

These problems became an important part of the learning process.

Instead of documenting only what worked, I decided to document the errors as well because understanding **why something failed and how it was diagnosed** is often more useful than simply memorizing the successful command.

As I continue developing the NBCM website, my goals are to:

1. Build a professional and trustworthy digital presence for NBCM.
2. Create a structured platform for historical and civic education.
3. Make NBCM's knowledge and educational resources easier to access.
4. Provide clear ways for visitors to learn, participate, volunteer, become members, and support the movement.

8. Become comfortable working directly with the application's source code.
9. Learn how modern frontend applications are structured and run locally.
10. Gradually take full technical ownership of the project.

---

## 13. Key Lesson

The most important lesson from the beginning of this project is that **generating a website and developing a website are not exactly the same thing**.

Lovable helped me generate and rapidly iterate on the application, but software development also involves understanding the source code, managing versions, configuring a development environment, testing changes, troubleshooting problems, and maintaining the project over time.

For me, the NBCM website represents the transition from simply using AI to generate software toward learning how to **work with AI while still understanding and controlling the development process**.
