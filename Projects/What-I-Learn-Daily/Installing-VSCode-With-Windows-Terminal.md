# Installing Visual Studio Code Through Windows Terminal

## Introduction

As part of my journey into web development, I wanted to learn how to install software using the command line instead of always downloading applications manually from a website.

In this documentation, I installed **Visual Studio Code (VS Code)** on Windows 11 using **Windows Terminal**, **PowerShell**, and the Windows Package Manager called **WinGet**.

During the process, I also encountered an issue where the `code` command was not immediately recognized after installation. I learned why this happened and how reopening the terminal solved the problem.

This exercise helped me understand more about:

- Windows Terminal
- PowerShell
- WinGet
- Package managers
- Software installation from the command line
- Environment variables
- The Windows `PATH`
- The VS Code `code` command
- Opening project folders directly from the terminal

# What is Visual Studio Code?

- HTML
- CSS
- JavaScript
- Python
- PHP
- C
- C++
- Java
- TypeScript
